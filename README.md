# Чёрный Клинок — бой с боссом в духе Elden Ring

Играть в браузере (телефон или ПК): https://zalupakonya777.github.io/black-blade/

Телефон держите горизонтально. Слева — стик движения, справа — свайп камерой и кнопки:
Удар, Сильный (удерживать — заряд), Кувырок (удерживать — бег), Блок, Прыжок, Умение, Фляга, Цель (захват).
На ПК: WASD, мышь, Пробел — кувырок/бег, ЛКМ — удар, Shift+ЛКМ — сильный, ПКМ — блок, F — прыжок, Q — цель, R — фляга.

Сделано на Godot 4.3. Звуки и музыка — CC0 / CC-BY (список авторов в меню игры).
